# @agenvo/t3code

[简体中文](README.zh-CN.md)

Sign in to a running T3 Code environment through its native MCP server. Discover projects and threads, including threads other clients started, start threads, submit input, read output, answer pending questions and interrupt runs. Closing the Connector leaves the environment and its runs untouched.

Requires Node.js 24.13+. This new Connector is available from source; no npm release is published yet.

[Build, configure and use T3 Code](https://github.com/Xuanwo/agenvo/blob/main/docs/t3code.md)
